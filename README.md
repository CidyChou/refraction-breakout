# 折射突围 v6

## 运行
```bash
./start.sh
```
浏览器打开 `http://localhost:8765`。

## 本版重点
- 修正瞄准线与实际子弹发射点：都从机头 muzzle 出发。
- 直射伤害调整为 30%，1 次反弹约 170%，明确鼓励借墙攻击。
- 开局墙体不再自带 SLOW / BURN，只提供反弹增伤。
- SLOW / BURN 改为局内升级「寒霜镀层 / 灼热镀层」解锁与强化。
- 首次升级会保证至少出现一个墙体属性升级作为可选项，但不会自动获得。
- 新增 Spinner / Pulse 敌人，并给全部敌人加入呼吸、轻微步进、旋转、外圈滚动等动态表现。
- 分裂技能只有在至少解锁一种墙体属性后才进入升级池，避免拿到无效技能。


## v7 音效
- 发射：短促科幻脉冲，音量较轻，避免自动射击过吵。
- 反弹：左右墙使用不同音高，连续反弹音高会轻微变化。
- 命中 / 击杀：区分普通命中与击杀爆破。
- SLOW / BURN：分别使用冰感高频与燃烧噪声提示。
- 升级 / Break Through / Core 受击 / Game Over：加入节奏节点反馈。
- 右上角 `SFX ON/OFF` 可随时关闭，设置会保存在浏览器本地。
- 当前版本使用 Web Audio 程序化合成，无额外音频资源体积；后续可无缝替换为 CC0 素材。


## v7.1 音效调整
- 发射音改为更清亮的 arcade / glassy `bling` 音色。
- 高频瞬态 + 短促下滑 + 轻微随机音高，连续射击时更像 `bling bling bling`，减少闷重枪声感。


## v8 UI 更新
- 升级卡片整体放大，信息层级重新设计。
- 三张卡片按 150ms 间隔依次砸入：DUANG → DUANG → DUANG。
- 卡片进场包含下落、压缩、回弹、扫光和边缘发光。
- 每张卡片出现时配套独立的低频冲击 + 金属高频音效。
- 点击选择时强化选中卡，其余卡片快速退场弱化。


## v9 GM 快速测试工具

游戏内点击 `GM`，或按 `F2` / 反引号 `` ` `` 打开。

- 任意技能直接 +1，并显示当前 GM 技能等级。
- 一键清空当前波次并进入下一波。
- 跳转到指定 Wave（保留当前 Build）。
- 增加 XP / 立即打开升级三选一。
- 恢复 Core、核心无敌、暂停 / 恢复。
- 直接设置 Fire CD、反弹次数、0.5x~4x 时间倍率。
- 墙 Buff 一键 MAX、反弹 +5、Build 重置。
- 指定生成 Grunt / Shield / Spinner / Splitter / Pulse / Warden / Drifter。
- 一键清空当前子弹，方便验证单独机制。


## v10 · Slow Horde Balance
- 敌人整体下移速度显著降低，Wave 压力成长改为更平缓的曲线。
- 普通敌人基础生命提高，并随 Wave 稳定成长；Shield / Warden / Splitter 等进一步提高耐久。
- 单波敌人数上限由约 30 提升到 54，后期更容易形成屏幕堆怪。
- 后期生成间隔逐步缩短，但不靠提高单体移动速度制造难度。
- SLOW 持续时间增加，适合把大群敌人控在场上。
- BURN 改为更长持续、更平滑的 DOT，不追求瞬间爆发。
- Splitter 生成的小怪也更耐打、更慢，避免出现“瞬间清空”的碎片感。

目标体验：**慢速压迫 → 堆怪 → 减速控场 → Buff 扩散 → 持续磨血 → 成片死亡。**
