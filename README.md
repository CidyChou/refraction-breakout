# 折射突围 v15.2 · Enemy Detail

本版聚焦战斗细节：

- 敌人速度重新分层：高速轻怪 / 中速功能怪 / 慢速坦克。
- 恢复几何敌人轮廓：三角、方形、菱形、六边形、八边形等。

- 三选一界面降低遮罩强度，选择战机时仍能看到战场变化。
- 保留传送门刷怪、无限墙面反弹、Hit Count + Lifetime、Buff Field、自由放置、独立瞄准、合成与金币单机升级。
